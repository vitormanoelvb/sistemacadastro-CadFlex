OBRIGADO POR UTILIZAR O SISTEMA!

Este sistema foi desenvolvido como parte da disciplina de Programação Orientada a Objetos (POO),
no curso de Sistemas de Informação da Universidade Vale do Rio Doce – UNIVALE, 3º Período.

O projeto foi criado com dedicação para aplicar os principais conceitos de POO:

• Criação de classes  
• Controle de acesso e segurança  
• Encapsulamento  
• Herança  
• Polimorfismo  
• Arquitetura MVC (Model-View-Controller)  
• Integração com Banco de Dados

Telas desenvolvidas:
• Tela de Login  
• Tela de Registro  
• Cadastro de Produto  
   - Incluir  
   - Alterar  
   - Excluir

Todos os módulos foram implementados com atenção aos princípios de organização, segurança e usabilidade.

Agradeço por testar este projeto acadêmico!
